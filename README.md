# Personal Portfolio

A personal portfolio website showcasing my projects, skills, and all my most of the frontend related works.

## 🚀 Features
- 👋 **About Me Section** – Quick intro about who I am and what I do.
- 💻 **Projects Showcase** – Highlights of key projects with links to live demos and GitHub repos.
- 📱 **Responsive Design** – Optimized for all devices.

## 🛠 Tech Stack
- Next.js, Tailwind CSS
- Framer Motion for animations
- Deployed on Vercel

🔗 [Live Demo](https://portfolio-ruddy-five-76.vercel.app/)
